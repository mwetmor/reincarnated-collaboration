Architecture and conventions (settled up-front)
═════════════════════════════════════

- TypeScript, not vanilla JS. Type safety on the JSON contract is high-value.
- **Pixi.js for rendering** (v7+). Vite for build tooling. No heavy frameworks (no React/Vue/etc.); the demo uses vanilla DOM + Pixi.js application.
- 2D top-down view, ARPG conventions. Combatants are sprites; abilities are particle effects + sprites; arena is a tiled or single-image background.
- Browser-only target. JSON exports loaded via fetch from a co-located /assets/seasons directory.
- Performance target: 60 FPS at 1080p on a modern MacBook. Pixi.js comfortably handles this for the demo's complexity.
- Damage math re-implemented in TypeScript per damage_formula.md. Don't try to call the Python engine at runtime.
- Zero engine code modifications. If you need data the engine doesn't export, file a request in collaboration-handoff/ (next available file number) and route through Matt.
- One playable class progresses through wave-structured gauntlet (trash → elite → 3 act-bosses) per playthrough. Player and opponents stationary in demo1.
- **Visual content generation: see file 25** for the detailed scope and tiered approach (programmatic procedural → composed sprite atoms from open libraries → AI-generated → hand-crafted). Visual content R&D runs as an iterative ongoing concern across all phases, not as a single phase. File 25 also covers ground-state gear highlighting (color-tiered glow on dropped items).
- **Audio content generation: see file 26** for the detailed scope. Five categories — ability SFX (matched to LLM names + geometry × element), hit/damage SFX, death SFX (tier-graded), rare+ drop chimes, and class/season-themed music. Same tiered approach as visuals (procedural Web Audio → curated CC0 libraries → AI-generated music + signature SFX → composed). Audio R&D runs in parallel with visual R&D as an ongoing concern.
- Project structure suggestion (refine as needed):
  src/

    visuals/                 # sprite generation/curation, particle systems, color shaders
