## 2. Sketch B — Per-Cell Coverage Floor

**The genre average per-build viable-weapon-pool is ~30-50 weapons; multi-season demand for v1 is ~50-150 per cell.**

### 2.1 Per-cell floor magnitudes (revised genre-aligned)

| Cell type | Floor (compatible weapons) | Reasoning |
|---|---|---|
| Pure-attacker melee cells | **80-120 weapons** per cell | Multi-season variety + per-playthrough selection variety + Tier-S/A headroom |
| Pure-attacker ranged cells | **60-100 weapons** per cell | Similar but weapon-impact less constant for ranged |
| Pure-attacker mid-range cells | **60-100 weapons** per cell | Same as ranged |
| Light proxy cells | **40-60 weapons** per cell | Proxy identity reduces weapon-dependence but main-weapon still matters |
| Heavy proxy cells | **30-50 weapons** per cell | Proxy identity dominates; weapon variety less critical |
| Cell hosting Tier-S named-mythological form | **+10-15 to floor** | Tier-S protection eats pool quickly; need headroom |
| Cell using off-hand items (Sidecar B) | **+30-50 off-hand items per cell** | Off-hand variety matched to weapon variety |

### 2.2 v1_scope size implication

| Category | Estimated v1_scope items |
|---|---|
| Main weapons (22 cells × ~70 avg floor / 2.5 utilization) | ~600-800 unique |
| Tier-S/A protection (22 cells × ~12 protected items) | ~260 additional |
| **Subtotal main weapons** | **~860-1,100 weapons** |
| Off-hand items (10-15 cells × ~40 floor / 2 utilization) | ~200-300 |
| **Subtotal off-hand** | **~200-300 items** |
| **TOTAL v1_scope** | **~1,100-1,400 items** |
| **% of total substrate (~70-74K)** | **~1.5-2%** |

### 2.3 Sourcing the substrate

Cycle 10 Stage 3 constrained-sampling locks v1_scope membership. Composition policy ensures:
- Each populated cell hits its floor via substrate selection
- Tier-S/A protection pre-commits exceptional items
- Substrate optionality preserved for v1.1+ work (non-v1_scope items stay in substrate per Variant C)

## 3. Sketch C — Geometry Distribution Intent

**Locked: 3-4 dominant + 1-2 niche geometries per cell; beams from skill side only.**

### 3.1 Geometry palette working categories

| Category | Examples |
|---|---|
| single | point-strike; single-projectile; precision-hit |
| multi-hit | twin-strike; multi-projectile; rapid-strike-on-target |
| cleave | arc-strike through adjacent enemies; horizontal sweep |
| AoE | area-of-effect; explosion-radius; ground-slam |
| beam / line | continuous beam; piercing-line; channeled stream (**SKILL-SIDE ONLY; not substrate-resident**) |
| scatter / cone | spread-projectile; cone-AoE; fan-shot |

### 3.2 Per-cell-type geometry distribution

| Cell type | Dominant (60-70%) | Secondary (20-30%) | Niche (≤10%) |
|---|---|---|---|
| Melee pure-attacker (STR/DEX) | single, cleave, sweep | multi-hit | arc |
| Mid-range pure-attacker (all attributes) | arc, cleave, line | single, AoE-small | scatter |
| Ranged pure-attacker (DEX) | single, multi-hit, line | scatter | - |
| Ranged caster (INT) | AoE, arc, line | single | multi-hit (orb-cycle) |
| Ranged channeler (WIS) | AoE, arc | single, line | scatter |
| Light proxy (any) | Match main weapon's profile | + proxy-geometry variety | - |
| Heavy proxy (any) | Minor variety in main (single + arc) | Proxies provide full geometry surface | - |

### 3.3 Aggregate v1_scope geometry shares

| Geometry category | Approximate v1_scope share |
|---|---|
| single | ~30% |
| cleave | ~20% |
| AoE | ~15% |
| multi-hit | ~12% |
| arc | ~10% |
| line (substrate-only) | ~8% |
| scatter / cone | ~5% |
| **beam (SKILL-side; not substrate)** | **0% in substrate; emerges in skill composition Phase 2** |

### 3.4 Discipline notes

- **Substrate-led variety preserved** — substrate provides geometric variety naturally; we keep more rather than less per cell
- **Beam geometry is SKILL-side** — Phase 2 skill composition can produce beam skills; substrate weapons don't need beam-property tagging
- **Cultural-tradition × geometry combinations** are FATE-GENRE-CRITICAL — different cultural traditions express cell-archetype via different geometric weapons (Japanese folklore: katana cleave-arc + kris multi-hit; Norse: greatsword cleave + war-hammer single-impact + axe sweep)

## 7. Sketch G — Per-Kit Skill-Budget

**Locked: ~11-13 nodes per kit; ~6-7 active / ~3-4 passive default; T4 distribution prediction ~35-40% / ~45-50% / ~15-20% for 0/1/2 T4 nodes; ω-field stacking + T4 trade-off + balance-loop disciplines enforced.**

### 7.1 Per-kit node distribution

| Category | Count per kit | Notes |
|---|---|---|
| Tier-1 (rotation) actives | 3-4 | Core attack pattern; not "filler" |
| Tier-2 (β-pair signature) actives | 2-3 | Identity-anchoring skills; adjacent-axis-overlap per skill-system § 5 |
| Tier-2 (mechanic-altering) passives | 3-4 | Mechanic-altering ONLY per § 3 discipline; NO filler stat-bonuses |
| Tier-3 (T4 build-defining) | 0-2 | Algorithmic mechanic-alteration; rare; active OR passive per skill-system § 8.4 |
| **TOTAL per kit** | **~11-13 nodes** | Within 10-15 budget |

### 7.2 Active/passive split variance per cell-type

| Cell type | Active/passive lean | Reasoning |
|---|---|---|
| Heavy proxy cells (Necromancer, Beastmaster, Witch Doctor) | Passive-heavy (~5/~6/+1-2 T4) | Passives buff proxies; main rotation thinner |
| Pure-attacker melee | Active-leaning (~8/~3/+1 T4) | Player IS the damage source; rotation matters |
| Pure-attacker ranged (Archer, Sniper) | Active-leaning (~7/~4/+1 T4) | Same |
| Channeling/caster | Even-split (~6/~5/+1 T4) | Channeling-actives + element-altering-passives both load-bearing |
| Mid-range hybrids | Even-split (~6/~5/+1 T4) | Variety lives in both layers |

### 7.3 T4 distribution PREDICTION (algorithm-emergent)

| T4 count per form | Revised prediction | Description |
|---|---|---|
| 0 T4 nodes | ~35-40% (~13-15 forms) | Pure rank-2 builds; identity from β-pair adjacent-axis-overlap; no regime-shift |
| 1 T4 node | ~45-50% (~17-18 forms) | Single algorithmic mechanic-alteration; build-defining identity around one regime-shift |
| 2 T4 nodes | ~15-20% (~5-7 forms) | "Legendary-tier" builds with dual regime-shifts; rare; algorithmic-richness peak |

**Total T4 manifestations:** ~17 + (2 × 6) = ~29 algorithmic mechanic-alterations to author across v1.

**Distribution is ALGORITHM-EMERGENT, not chosen.** Algorithm § 8 scans BC-axis space per kit and produces T4 alterations where η-coefficient opportunity exists. Balance-loop adjusts.

### 7.4 Balance discipline — rank-2 builds hit win-rate floor

Concern: pure rank-2 builds might lack power vs T4-augmented builds. **Three safeguards locked:**

| Safeguard | Description | Enforcement |
|---|---|---|
| **ω-field stacking depth for rank-2 builds** | Rank-2 builds compose deeper β-pair-supporting passives (PoE cluster-stacking style) — multiple mechanic-altering passives pointing at signature active | skill-system § 5; algorithm § 8 must compose β-pair-supporting passives when no T4 fires |
| **T4 trade-off discipline ENFORCED** | Algorithm § 8 produces only regime-change mechanics (Blood Magic-style trade-offs); NO raw power-shifts. T4 candidates that read as "+30% damage" rejected | skill-system § 6.2; cohesion judge + jack-ryan Gate-2 |
| **Balance-loop validation at Cycle 10 Stage 4** | Sim measures win-rate per form; forms below band get re-generated OR promoted to T4 OR removed | B14.5 V1 architecture; jack-ryan Gate-2; KI-B6-1 ±25% variance discipline |

### 7.5 Residual risk

Some forms may fall outside win-rate band even after re-generation / T4-promotion. Discipline: **form gets demoted from v1_scope OR cell gets re-evaluated for inclusion.** Substrate-led discipline says don't ship what doesn't work; v1.1+ can rescue specific cells with deeper design work.
