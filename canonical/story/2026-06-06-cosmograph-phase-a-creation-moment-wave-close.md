## 5. The interaction-architecture arc

Three distinct Pixi.js v7 event-routing nuances surfaced during Phases 5/5b/5c, each producing a substrate-led design call:

### 5.1 Lasso coord-transform (Phase 5b)

**Root cause:** `FederatedPointerEvent.globalX/Y` is Pixi global space (CSS-pixel pre-stage-transform). Phase 5's zoom + pan created non-identity stage transform; LassoLayer was passing global coords directly into `toUMAP` (which expects stage-local coords).

**Fix:** `toStageLocal(globalX, globalY, stage)` helper applying inverse `x = (globalX - stage.position.x) / stage.scale.x`. Same fix applied to faction-click hit-test (same bug class).

**Design call preserved:** `MIN_DRAG_PX` intentionally kept in screen-space — substrate-led judgment that a screen-pixel threshold should NOT scale with zoom (screen-space user-intent metric, not world-space distance).

### 5.2 Pan event-routing (Phase 5c)

**Initial hypothesis ranking:** delta-math errors topped the list. Empirical investigation surfaced this was wrong — the actual root cause was a **Pixi event-routing bug**: Pixi v7 dispatches `pointermove` via hit-test against the stage's `hitArea = Rectangle(0,0,w,h)` in stage-LOCAL coords. After pan, the hitArea's screen-space coverage shifts with the stage origin. When the cursor enters a region where stage-local position falls outside the hitArea, hit-test fails and `pointermove` stops being delivered mid-drag.

**Fix:** migrated pan + faction-click from Pixi federated events to native DOM events (`pointerdown` on container; `pointermove` + `pointerup` on document — mirrors the wheel-zoom handler pattern). LassoLayer federated events preserved (lasso needs Pixi's coordinate space).

**Pattern surfaced:** when a Pixi feature interacts with non-identity stage transforms over an extended drag, prefer native DOM event-routing.

### 5.3 Mode-toggle UX selection (Phase 5b)

Option A (pointer/lasso toolbar toggle with default Pointer + grab cursor; opt-in Lasso + crosshair cursor) chosen over alternatives. Substrate-led rationale: lasso is a deliberate selection action, not a default exploratory action; pan should be the default exploratory mode.
