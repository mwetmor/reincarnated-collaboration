### 1.5 The lineage-tag over-collapse

Independent of the cultural-coverage gap, the `oceanic` lineage tag itself collapses multiple distinct cultural-tradition families under one label:

- **Polynesian** (Maori NZ; Hawaiian; Samoan; Tongan; Tahitian; Cook Islands; Niuean; Tokelauan)
- **Aboriginal Australian** (~250+ distinct nations and language groups; Eora, Wiradjuri, Gunditjmara, Noongar, Yolngu, etc.)
- **Melanesian** (Fijian, Solomon Islander, Vanuatuan, Papuan, New Caledonian)
- **Micronesian** (Marshallese, Chamorro, Kiribati, Carolinian, Pohnpeian, Yapese)
- **Other Pacific Islander** (Rotuman, Niuean, Tokelauan, others not cleanly in the above)

A substrate-led approach to Pacific cultural-tradition representation should likely sub-categorize the `oceanic` lineage tag *before* substrate expansion runs (otherwise an expanded pool will continue to bundle culturally-distinct traditions under one label, producing the same problem at larger scale). This is sub-carry 9.11-D / 9.11-E territory.

### 1.6 Why this is compound failure, not single-mode failure

Oceanic is the **most compounding** of the four marginal lineages. It shows:

- **Substrate-coverage failure** (6-8 cultural items in a 39-row pool — proportionally tiny; in absolute terms below clustering threshold)
- **Substrate-tagging discipline failure** (21 of 39 rows are Australian/NZ modern military, captured by geographic-tagging-as-cultural-lineage)
- **Lineage-vocabulary over-collapse** (one tag for ~4-5 distinct cultural-tradition families)

All three modes compound. Any one would justify deferred-commitment framing; all three together make oceanic the strongest case among the 4 marginal lineages for substrate-led discipline + cleanup-before-expansion.

This disposition is **not**:

1. **Not a rejection of the Cluster 69 canonical label.** Phase E-2 labelled it "Cross-Cultural Contemporary Mixed-Munitions Pool" with framing_audit_notes that explicitly acknowledge oceanic absorption. That label is correct for what the cluster contains.
2. **Not a substrate-cleaning prescription.** Sub-carries 9.11-D and 9.11-E are elrond's queue.
3. **Not a statement about the design value of Pacific cultural weapon-making traditions.** Maori patu / mere / taiaha + Aboriginal woomera / nulla-nulla / boomerang + Polynesian leiomano + Fijian throwing clubs + Solomon Islands ceremonial shields are extraordinarily rich design seeds with strong distinct visual identities. The recognition is about the **current 89.8K-row substrate as currently tagged**, not about the eventual game.
4. **Not a clustering-methodology criticism.** mcs at any tested value would not surface a Pacific cultural-tradition cluster — the substrate doesn't contain enough culturally-coherent items in any single cultural-tradition family.

## 5. The lineage-tag over-collapse discipline (oceanic perspective)

Oceanic is the load-bearing case for the **substrate-vocabulary granularity** sub-discipline within the broader geographic-vs-cultural pattern. Where south_am and arctic illustrate "the cluster is real but the cultural-tradition is absent," oceanic adds "the lineage-tag itself is too coarse to capture the cultural-tradition diversity." This applies forward to:

- East_asian (similar over-collapse risk: Japanese + Chinese + Korean + Vietnamese + Mongolian + Tibetan + Filipino are all under one tag, each a distinct weapon-making tradition family)
- Southeast_asian (Khmer + Thai + Vietnamese + Burmese + Filipino + Indonesian + Malay + Lao under one tag)
- South_asian (Indian + Pakistani + Bangladeshi + Sri Lankan + Nepali + Bhutanese + plus many distinct sub-traditions: Sikh-kirpan + Rajput + Maratha + Tamil + Sinhalese)

Whenever a lineage-tag collapses ≥ 3 culturally-distinct weapon-making tradition families, the substrate-led clustering will tend to find geographic-region or modern-arms-manufacture coherence rather than cultural-tradition coherence. Sub-categorization is a substrate-discipline prerequisite to substrate-led cultural-tradition cluster emergence.
