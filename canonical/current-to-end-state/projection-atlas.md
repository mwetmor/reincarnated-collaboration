## §1 — Placement classes (the placement test made operational)

Every kit-varying Codex field projects to **exactly one** class. Mobile-track's coarse triple
{lattice dimension · configuration-within-cell · identity layer} refines to five operational
classes (the lattice-dimension class splits on sampled-vs-measured — a distinction the catalog/
archive architecture already enforces — and constraint machinery gets its own class so it is never
force-projected as a dimension):

| Class | Meaning | Lattice relation |
|---|---|---|
| **BC-SAMPLED** | catalog coordinate — the sampler draws it | L0 dimension (also appears as archive axis) |
| **BC-MEASURED** | archive axis the gauntlet measures; emergent, not drawn | L1/L2 dimension (catalog-blind — the R-2/R-3 rug class) |
| **IDENTITY** | rolled/derived at generation; definitionally counted, never BC-sampled (placement test) | L3/L4 factor |
| **WITHIN-CELL CONFIG** | expression texture below kit grain; does not multiply the lattice | `substrate-coordinates.md` §5 grain |
| **CONSTRAINT / TRANSFORM** | cuts, masks, pins, dials, T4 transforms — **maps ON the lattice, not dimensions OF it** | `substrate-coordinates.md` §4 |

**Scope rule:** the projection covers KIT-VARYING fields. Engine-global machinery (mitigation
branch, resistance matrix, geometry damage-ladder) is constant across all cells — listed in the
Codex, carries **no address** here, and is exempt from the §3 alarm.

## §3 — Alarm registers (the projection is instrumentation, both directions)

- **UNPROJECTABLE-FIELD ALARM (map is missing an axis, or the field is malformed):** a Codex field
  that projects to no class — or demands two — triggers **evidence-attached axis genesis**
  (Stage-N; admission gate = arity stress-test, ninth-axis precedent). This is no longer a
  brainstorm; it is a triggered process. **Both historical cases ran exactly this way before the
  register existed:** `bc_commitment` (E4 implemented commitment behavior the 8-axis archive could
  not see → ninth axis, stress-test-gated) and the rotational family (implemented spin/orbit
  behaviors projected to no cell → adjudicated → landed as motion-frame bundles + kernel slot,
  **0 new axes** — the alarm can resolve to WITHIN-CELL CONFIG, not only to genesis).
- **EMPTY-FEASIBLE-CELL REGISTER (the search frontier, enumerated):** lattice cells with zero
  occupancy whose coordinates violate no §4 cut and whose mechanics are Codex-expressible. This is
  Matt-process step 2's work queue — enumerated rather than intuited. Emitted by the Atlas (§4),
  never hand-listed. Composes with the FUN ladder (`substrate-coordinates.md` §7): frontier cells
  are CANDIDATES for exploration, certified only through the derivation ladder.
