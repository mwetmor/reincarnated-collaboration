# E08A — lossless frame packing and neutral atlas import

Independent G2/H12 preparation using the mechanically controlled, visually unqualified E05B frame set. Godot shipping target; Pixi test harness. Do not render new poses, modify paintings, promote gait/style or produce new characters. Trim only fully transparent exterior canvas, copy existing RGBA pixels into a padded atlas, and update each pivot/rect by the exact crop translation. No resampling, recolouring, alpha threshold cleanup or edge painting. This is deterministic packaging, not an art repair.

Freeze: every cropped source pixel equals its atlas pixel in all four channels; omitted exterior alpha is exactly zero; new pivot plus crop origin equals original pivot; every original frame can be reconstructed pixel-for-pixel (including transparent RGB, preserved separately only if needed). Atlas rectangles do not overlap and remain inside the image. Hashes,48 frames,60fps and0.8s timing remain traceable. Pixi loads the neutral rect/pivot metadata; matched source-vs-atlas composites at50/150px may differ by at most2 channel levels on ≤1% of canvas pixels, accounting only for texture-coordinate arithmetic. Bad controls: shifted rect, shifted pivot and wrong fps must be rejected by their relevant checks.

Limits: zero imagegen/paid calls,30min active,≤2 browser batches,≤20MB owned disk. Reserve capacity before captures. Report uncompressed RGBA texel allocation separately from measured GPU memory; no production-performance pass or100-character capacity claim. Leave source frames immutable and report any nonzero transparent-RGB preservation issue rather than silently discarding data.

Preserve that candidate and its102 structural checks; it is not a packing efficiency pass. Store invisible exterior RGB in a standard gzip JSON archival sidecar, trim using exact alpha>0 bounds plus2 pixels, and reconstruct all original RGBA through atlas+sidecar. Runtime compositing must still meet the unchanged pixel tolerance. No source art pixels, opacity or thresholds are modified.
