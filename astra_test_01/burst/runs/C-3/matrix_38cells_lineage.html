Number definitions

All numbers are reports against proposed bands; none is a pass or fail.

G6b in the cells is raw endpoint seam MAD, not a ratio. G6 (literal) remains the recorded brief gate; G6b is a second instrument. Whether G6b becomes the shipping bar is Matt's ruling at the first-loop milestone. Closure compares animation endpoints for loops and rest to final frame for jump/cast. G1 max and motion range are fractions, not percentages.

cell
Matrix key <animation>_<DIR>; rows ordered by S SW W NW N NE E SE, then idle walk run jump cast; only cells with named frame inputs are included.
n_frames
Count of animation PNG frames in the named cell, ordered by numeric filename suffix; rest is excluded.
fps_out
Playback frames per second copied from the cell registration.json top-level fps_out.
G6b
Frozen g6_seam.evaluate(frames) g6b value: last-to-first RGB MAD over the entire canvas after PIL alpha compositing on RGB (20,25,34), in display RGB units 0..255; this is raw MAD, not a ratio, and uses animation endpoints even for one-shots.
G6b_median_internal_mad
Frozen g6_seam.evaluate(frames) g6b threshold: median full-canvas composited RGB MAD across internal adjacent animation-frame pairs; retained as a descriptive comparator only.
G6_literal_min_internal_mad
Frozen g6_seam.evaluate(frames) g6_seam threshold: minimum full-canvas composited RGB MAD across internal adjacent animation-frame pairs; its measured seam value is identical to G6b.
G6c
For walk/run only, frozen g6_seam.g6c(frames, animation="walk") value: full-canvas composited seam MAD (N-1,0) divided by half-cycle homologue MAD (N/2-1,N/2); the walk-only function mode is used for both gait types as requested; 0/0 is 1, positive/0 is null with G6c_ratio_infinite true; other animations are null.
G6c_homologue_mad
Walk/run half-cycle homologue MAD from frozen g6c notes, in full-canvas composited RGB units 0..255; null for other animations.
