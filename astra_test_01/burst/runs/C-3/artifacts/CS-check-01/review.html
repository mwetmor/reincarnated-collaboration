Method notes

Step-3 vista uniform scale 1.833333333; screen vista uniform scale 1.855468750. Screen world crop: (624, −438) to (2544, 642). The entire screen uses the extended vista transform, so no fill seam is introduced.

  • Frozen matte border precondition rejected both edge-reaching chunks; one shared padding adaptation was applied in memory, then cropped back to original extent.
  • Frozen extractor retains only the largest connected component and its 3-px support by default; measurements describe that specified extractor output.
  • The screen needs 438 px above the assembled canvas. Its vista uses scale 1.855468750 instead of 1.833333333 to continue a centred background without missing pixels.
  • No gate thresholds or visual verdicts were applied.
  • The screen exposes the hard top boundary of the supplied first-portion chunks at world y=0 (screen y=438); no additional foreground was invented.
  • Character sampling uses exactly equal horizontal and vertical scale with transparent lateral raster padding; shadows are centred to subpixel precision.
