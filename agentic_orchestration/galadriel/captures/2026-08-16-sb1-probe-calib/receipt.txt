8. DEFECTS FOUND, WITH ATTRIBUTION
--------------------------------------------------------------------------------
D-1  FOUND-BY-SMOKE (this cell's own first leg-A lap). SEVERITY: would have
     shipped a hollow receipt line.
     The probe's HEIGHT ASSERTION print carried SIX format conversions against
     FIVE arguments. GDScript's `%` does not raise and does not warn on a count
     mismatch — it returns the FORMAT STRING UNCHANGED. The line printed a literal
     `%s` where the PASS/FAIL verdict belonged. (Cousin of NOTE-81, which records
     the same silent-passthrough behaviour for `%e`.)
     The SUBSTANTIVE assertion was never compromised: the `ok` boolean, the HALT
     branch and the sidecar (`height_err_m` 0.0, `assertion` "PASS") were all
     correct throughout. Only the human-readable line was broken.
     FIXED: each `%` kept adjacent to its own array so the counts can be checked
     by eye (2/2, 4/4, 2/2). Leg A was RE-RENDERED on the fixed script and came
     back with the SAME sha (41a6a8bd...), confirming the fix moved zero rendered
     bytes.

D-2  FOUND-BY-GATE, and it is a defect in THIS CELL'S OWN GATE — the more
     important half of D-1.
     The runner gated the read-back by looking for the ABSENCE of "FAIL". A broken
     format string satisfies that test exactly as well as a passing probe does, so
     the gate went green on a line containing neither PASS nor FAIL. An
     absence-based gate passes when its instrument breaks.
     FIXED: the gate now requires the POSITIVE token "VERDICT PASS", once per
     pass, and counts assertion lines separately so a MISSING line and a FAILING
     line are two distinct HALTs.

D-3  FOUND-BY-SMOKE (first delivery lap). The scene names its sidecar after the
     SHOT (`shot-A-stationary-canon.json`) and both legs render the same shot, so
     a straight copy had leg B silently overwriting leg A's read-back — a NOTE-95
     label collision. FIXED: sidecars are promoted under leg-tagged names.

D-4  FOUND-BY-SMOKE, PRE-EXISTING, NOT THIS CELL'S CODE. The wr2/BR2W reference
     rig is not byte-deterministic lap to lap — see § 6 for the three-lap evidence
     and the frame-by-frame table. Present in the PRISTINE HEAD script. Routed to
     the conductor as a finding about the reference rig; NOT diagnosed here.

D-5  FOUND-BY-SMOKE, this session's own invocation, no code impact. A first Leg C
     probe was wrapped in `timeout 500`, which does not exist on macOS
     (GNU coreutils; `gtimeout` if installed). The wrapper failed before Godot
     launched and the failure was hidden by an output filter. Re-run without it.
     Recorded because a silent zero-frame run that looks like a render failure is
     worth one line in a receipt.
