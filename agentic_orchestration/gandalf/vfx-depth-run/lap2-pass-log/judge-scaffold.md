## Why this file exists

The conductor-side comparison of X-3/X-4 against X-1/X-2 **IS** the lap-2 gap-narrowing measurement (charter §4; R-25 NEXT clause). The run's negative-control law binds the judge as much as any instrument: **a prediction formed after reading the output it judges is not a prediction.** So the family-level expectations are registered here first. When X-3/X-4 land, each row gets an OBSERVED column and a verdict — CONFIRMED / REFUTED / PARTIAL — and refutations of the conductor's predictions are findings, not embarrassments (cf. R-25's T-3(a) route correction: "conclusion stood, reasoning did not").

## § 1 — Judge protocol (fixed now)

1. Log X-3/X-4 outputs **verbatim** to `X-3.md` / `X-4.md` in this directory (same format as lap-1 logs).
2. Map every ranked difference + per-dimension differential in each pass to a registry family (or NONE → I-1 residual candidate). Mapping is post-hoc and conductor-side; seats saw no registry vocabulary.
3. Score each § 2 row against BOTH passes: a family "drops" only if **neither** pass ranks it top-5 AND neither describes it as categorical absence; it "weakens" if described as present-but-deficient; it "persists" if either pass reports categorical absence or ranks it top-3.
4. Cross-pass divergences are signal, not noise (lap-1 precedent: X-1/X-2 event-structure parsing divergence → audit question).
5. Novel residuals → I-1 PROVISIONAL candidates, evidence frames required, jack-ryan ratification queue.
6. **Honesty clause:** if X-3/X-4 rank the SAME top-3 as X-1/X-2, the lap-2 build did not move the perceptual needle regardless of what the battery measured — that verdict goes to Matt's gate packet undiluted. Instruments passing while eyes don't is the exact gap this blind-judge stage exists to catch.

## § 3 — Pre-registered judge risks

- **R-a:** Seats compare against the SAME reference but a DIFFERENT render duration/window than lap-1 seats saw (lap-1: 3.5 s W2 B-arm; lap-2: 4.80 s, window 0.20→5.00 s). Duration-class observations must be discounted as production differences per both lap-1 seats' own practice.
- **R-b:** Protocol v2 has 11 dimensions vs v1's 10. Per-dimension counts are not directly comparable; comparison operates at the family-mapping layer, not the dimension-count layer.
- **R-c:** If a seat independently re-derives a treatment's *mechanism* (e.g., "the arc appears to have an attached light source"), that is evidence of visibility, not contamination — mechanisms are inferable from pixels. Contamination would be registry/family/treatment VOCABULARY, which the seats were never shown.
