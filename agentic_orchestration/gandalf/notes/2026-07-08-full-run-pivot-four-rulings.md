## 2. The four rulings (decomposed by gandalf, ratified by Matt as a set)

**(a) The seed-57000000 population is SCRAPPED.** The 1,800-kit population (18 BC cells × 100
samples) is no longer the certification target and never becomes content. Near-costless by
construction: the KPM bands must re-fit at each newly declared baseline anyway (gear ruling
already established this); the pilot machinery is population-agnostic; the F1 pilot's kit-grain
findings survive as **instrument evidence** (they certified the instrument, not the kits).

**(b) The demo is RE-SOURCED, not scrapped.** The demo remains **THE DENOMINATOR** (scope
anchor — `one-realm-mvp-scope.md` unchanged as scope law). What dies is **"sprint-to-demo" as a
trivialization license** — the framing that inverted the project's orientation anchor ("Engine
first. Game second. Phase third." — CLAUDE.md; sprint-to-demo ran it backwards). The roster
becomes **Matt-curated ~20, hand-picked from the full-spec population**, individually
**kit-grain certified** (the Leg-ii GRAIN design anticipated exactly this: roster-sized kit-grain
cert while population cert stays cell-grain). Count note: "20" supersedes the 2026-07-06
18-kit=18-cell 1:1 count on the count axis; whether cell-coverage survives as a curation
constraint is Matt's choice at pick time (gandalf lean: preserve breadth). The 2026-07-02
"zero hand-authored shipped content" ruling SURVIVES — curation ≠ authorship; kits are still
engine-generated + sim-certified; Matt picks, never writes.

**(c) The full-spec engine is the MAIN LINE.** Variation axes land **per-axis** with the
generate → sim → certify rhythm — NOT big-bang. First axis: **skill-geometry widening**
(rocket; the emitter table → the rich palette the sim already consumes). Each axis lands, the
population regenerates, bands re-fit at the new declared baseline, the pilot re-runs as the
per-axis certification gate. The pilot instrument thereby converts from one-shot to **the
standing per-axis instrument** — the halt's completion-build is main-line work, not salvage.

**(d) The trivialization audit is COMMISSIONED.** Every seam, survey-mode (what-IS, cited),
classification **FLIP / FLAG / KEEP** per OP §3.7 (FLIP = spec needs it, gap-to-close; FLAG =
Matt fork; KEEP = genuine layer-handoff or sequenced work), each row carrying spec citations.
"I cringe to think of what else was trivialized" is the commission. Findings land as
surface-ledger rows as they surface — not as a monolithic report.

## 3. The fifth directive — the SURFACE LEDGER (the visualization + the gate)

Matt's turn-2 directive operationalized: **`canonical/current-to-end-state/surface-ledger.md`**
— a living queue-row table (Surface | Current state | Classification | Matt gate) in the four
domains Matt named (**engine / story / demo-game / content-emission**), written in the Glance
parse shapes (§2.1 STATUS · §2.2 SESSION-DELTA · §2.3 queue rows · §2.4 gates-on · §2.7 FLOW)
so it renders in Glance **derived-never-authored** — zero new parser logic, one more glob
(contract v1.3 §7.2). Row lifecycle:

```
⚖ (surfaced, classification = gandalf lean)
   → Matt rules → KEEP: ✓ agreed as-is
                → FLIP: IN-FLIGHT (gap-to-close fires) → ✓ when landed + Matt-seen
                → FLAG: stays ⚖ with the fork named → ruled → FLIP/KEEP path
```

**THE GATE (Matt's sentence, made structural):** the ledger carries a `GATE1` row —
`gates-on: all-surfaces-agreed` (named gate; closes when every ledger row reads ✓). **No demo
assembly proceeds and no emission of any size fires until GATE1 closes.** This SUPERSEDES the
earlier, weaker emission gate ("pilot verdicts + rulings close") — strictly stronger.

Scope discipline: the ledger is **NOT a fifth copy of the trackers.** Trackers = what the work
owes the spec (full build queues). Ledger = **the trivialization-audit surfaces + Matt's
per-surface agreement state** — the demo gate, row by row. Ledger rows cross-reference tracker
rows where they exist.
