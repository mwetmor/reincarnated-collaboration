## The line (publication-grade)

> A kit is **treatment=hybrid** only when damage and control are co-equal, hardlocked halves of the kit's designed identity — the **deletion test**: remove either half and the kit collapses; remove neither by configuration. Control that rides the damage chain is a **rider-proc**, not a treatment half: a pull that exists to trigger a damage buff (Strongarm + Ess of Johan), a debuff that is damage amplification wearing control's clothes (Vulnerability-on-hit), grouping that feeds someone else's burst window (zBarb pixelpull), a DoT misread as control (Warpath Ignite — damage ailment ≠ control ailment). Every genre near-miss escapes the wedge by one of four doors: the control is **vestigial** (zMonk's trivial damage inverted), **suppressed by design** (zBarb gears AGAINST its own damage), **configurable-out** (DI Cyclone Strike — Storm Spirit removes the pull, so the hybrid is a player option, not a kit identity), or **gear-assembled** (MCD Gravity — an enchant economy, no class carries it intrinsically). The wedge stands: no shipped kit hardlocks both halves.

## Deletion test — operational form (for elrond's assignment memo)

1. **Remove the damage half.** Does the remaining control constitute a viable standalone role for THIS kit as designed (not as a party-support reconfiguration)? If yes → control-primary, not hybrid.
2. **Remove the control half.** Does the kit still function as a damage kit (even degraded)? If yes → damage-primary with rider; not hybrid. *Degraded-but-operable fails the collapse bar* — MCD gravity removal degrades efficiency, does not inoperate the build.
3. **Configuration probe.** Does a sanctioned variant of the same kit de-emphasize either half (DI Storm Spirit; zMonk damage-suppression)? If yes → the hybrid is not hardlocked; not treatment=hybrid.
4. **Assembly probe.** Is the control half intrinsic to the kit's class/skill identity, or assembled via items/enchants/affixes? Assembled → rider-proc lineage, not treatment.

All four must pass for hybrid assignment. Asymmetry anywhere → assign the primary treatment + annotate the rider.
