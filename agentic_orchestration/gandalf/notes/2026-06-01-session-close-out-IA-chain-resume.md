## 3. Manifestation Milestone Phase 1 vision-clarification

### 3.1 The reframing

Matt's actual MM-P1 vision is **a visually compelling video-performance mock-up** of the character creation experience, not just engine-side JSON output.

### 3.2 Four-stage character creation flow

| Stage | What player experiences | VFX | Sound |
|---|---|---|---|
| **A. Celestial Spirit** | Animated celestial spirit forms; player explores via gallery/deck pattern; lands on specific kit (e.g., "Bone Necromancer of Dragonstone") | **VFX SURFACE 1** — auras, flowing-wind movement effects, elemental glows | Per-element sonic signatures; ambient celestial atmosphere; UI selection feedback |
| **B. Materialization** | Selected character appears in tattered period clothing | Cloth physics; minimal VFX | Manifestation cue; period-appropriate material sounds |
| **C. Customization** | Player adjusts gender / hair / facial features / skin color / faction tattoos | Cosmetic only | Subtle UI feedback |
| **D. L50 Decked-Out Reveal** | Player greeted by L50 version of their character; Tier 2 Set + Legendary gear; skill + gear auras active | **VFX SURFACE 2** — skill auras + gear auras + faction-tattoo glow | "Boom" entrance audio; gear-settling; aura humming; skill-passive idle layers |

### 3.3 Critical scope reductions Matt surfaced

**Reduction 1 — Chernoff is mock, not full implementation:**
- NOT the full chernoff data-to-feature mathematical mapping
- NOT a continuous parameter space
- NOT real-time parameter response
- IS a visually compelling video-performance mock that demonstrates what the system COULD do when fully implemented
- "Modest effort + purchased modular character/armor/VFX packs" is the path

**Reduction 2 — Stage A is 3d art, not moldable substrate:**
- Stage A becomes a gallery/deck of celestial spirit 3d art
- Pre-rendered per kit candidate; player browses/swipes/filters
- NO moldability mechanic; NO continuous parameter exploration
- "Play around" = browse/swipe through the discrete kit candidate set
- Alternative: filtered-discrete pattern (player filters by element/period/cultural-tradition; gallery shows matching candidates)

**Reduction 3 — Only one character maps from engine gen JSON:**
- The ONE character the player is "molding towards" and "selecting" gets full engine JSON → 3d art + materialization + customization + L50 reveal mapping
- Other candidates are lighter-weight representations (card-art / silhouettes / placeholders)
- Implementation focuses on a SINGLE character pipeline rather than ~34

### 3.4 Three parallel substrate dimensions

The chernoff mock data substrate has three dimensions (significantly simplified per reductions above):

1. **Visual features** — color values (per canonical color spectrum), aura specs, glow parameters, spirit-form shape, cloth/material/gear visual
2. **VFX features** — particle effects per element, movement effects, elemental glows, skill auras, gear auras
3. **Sound features** — element sonic signatures, stage atmosphere, UI feedback, manifestation cues, reveal stings

All three compose with substrate inputs (primary element + sub-element + period + cultural-tradition + register + tier).
