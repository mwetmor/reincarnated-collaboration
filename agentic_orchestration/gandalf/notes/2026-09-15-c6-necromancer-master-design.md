## Weapon architecture (proposed; Matt rules)
- **Grip classes drive animation; weapons are socketed layers.** Classes: 2H-polearm (scythe / staff / spear) · 1H + off-hand (dagger or wand + orb / book / bone-claw) · empty-hands caster. One animation set per class; the Keeper's staff set = the 2H-polearm set.
- A weapon = a separate per-frame sprite attached at the hand socket with the per-frame rotation the T3i staff-tip instrument measures; painted once per direction from the master's grip; swap = layer change, motion-identical (the P5 gear-layer mechanism — proven here or not).
- Off-hand items are gear layers on the same socket logic (the bone-claw gauntlet + skull cage = the necromancer's advanced off-hand).
- First proof: necromancer 2H set with the scythe layer; the same frames with the Keeper's staff swapped in.
- Alternatives (rejected as recommendation): a set per weapon (N × 40 clips); weapon painted into the body (the lock Matt does not want).
