## 3 · Design rulings resolved in the eliciting dialogue (in-run these are LAW; reopening = HALT)

1. **Archetype-first factory shape** — one canonical VFX per skill archetype, variation as
   parameter layers (D3 rune-system / PoE gem+MTX precedent). Never bespoke-per-kit-skill.
2. **Selection criterion ("best" is judged, not vibed):** readability at our gameplay camera ·
   parameterizability (recolor/scale/motif-swap survivable) · style-register fit. Galadriel
   scores; receipts filed.
3. **Two-tier variation:** Tier-1 element parameterization (palette / motif / trail texture)
   ships WITH the base mapping — a fire whirlwind and an ice whirlwind differ at base, or kits
   read as reskins. Tier-2 bespoke signature flourish is deferred and deserving-based (the one or
   two skills carrying a kit's fantasy); the deserving list is **Matt's ratification**, not the
   run's.
4. **Reference-anchoring boundary (stated once, permanently):** reference imagery anchors **skill
   semantics + readability** — "same move, our style" — mediated by the locked style register
   (`reap-die-rise-story/style-register.md`). Never pixel-style imitation. The sim-side Law-3
   referent-figure quarantine is a different layer and is untouched.
5. **Matt manual capture = fallback lane only** — per-skill `matt_to_do/` rows, filed only after
   both automated lanes (Codex research, legolas) come back empty.
6. **Player consequence anchor:** shared archetype VFX = telegraph literacy — the player learns
   the visual language once; element tint reads damage type on sight.
