# VFX workflow architecture — the synthesis (proposal for Matt's ruling)

> **STATUS:** PROPOSAL v2.2 — gandalf (ARCHITECT / SPEC-AUTHOR), 2026-09-15. **Re-scoped on Matt's correction** (verbatim: *"Constraining our VFX production pipeline around a content generator we haven't ran in months before we even know if we can develop a VFX workflow at all is illogical."*). **GOAL = develop a workflow that can generate VFX similar to the 6 selected VFX, within a register similar to our 2D scene.** Nothing here depends on the content generator, the emitted corpus, or the engine's geometry palette; v1's generator coupling is parked in `04-parked-generator-coupling.md`. Astra's red-team (`02d-`) is folded in with ⟲ marks. Inputs: dossier `00-`, prior `01-`, Astra `02a-`/`02c-`/`02d-`, Legolas probes 1 + 2. **Not canon until Matt rules § 7.** Every numeric tolerance below is a *proposed project gate* whose yield E1/E2 must establish (⟲ Astra).

## 0. TL;DR

⟲ **Useful drawings failed inside an incomplete system.** Both lanes that held share one shape — *the image model supplies a still; something else supplies time; structure is approved before paint; the anchor enters through the canvas; coherence is structural* — and the VFX breadth test had none of it. The workflow below is that shape applied to six effects:

> **Grammar lives in the runtime. Primitives live in sheets. The anchor is a still. Time is never inferred from sheet order. Coherence is shared construction, repeatedly compared — the layer stack is its necessary discipline.**

- **Time owner:** Godot itself. The Hades layer stack (painted body + black MIX duplicate of the same sheet + flash + floor light + decal) is expressible natively (`CanvasItemMaterial.particles_animation` + `blend_mode` + `light_mode`; `PointLight2D`) — Legolas probe 2, VERIFIED. ⟲ Custom palette lookup / erosion need a shared `ShaderMaterial`, and the web playtest's **GL Compatibility** renderer excludes `emit_particle()`, trails and GPU sub-emitters — so heads, links and scheduled children are **pooled sprites/nodes**, trails are `Line2D`/ribbons, and Compatibility + browser parity is the acceptance bar. Movie Maker bakes deterministic alpha PNG sequences; flipbook-vs-runtime is a per-effect **dial**.
- **Four motion grammars cover the six skills** (§ 2.2); parameters hand-entered per skill from the source game — **six hand-authored specs, no engine dependency.**
- **Still owner:** Astra paints a small primitive alphabet (≈ 8 shared + 2–4 per element, five elements) against an **anchor package derived from the scene**, one primitive per call, three images per brief.
- **Structure before paint:** a **VFX grey room** — grey bodies moving in the live cliffside with a target dummy and an aim rule — **Matt sees a 3-second clip before any painting**; the approved instant becomes the size/timing spec and the paint-over guide.
- ⟲ **Order:** prerequisites (runtime spine + renderer lock) → E0 (£0 stack proof) → grey room → E1 (procedural vs painted, ≤ 8 images) → E2 (fire × ice, projectile × field, ≤ 12) → the six.

## 2. The workflow — three contracts

### 2.1 Contract I — the skill spec (six hand-authored files)

One `VfxSkillSpec` per selected skill, written by the conductor from the source game and Matt's intent — **no field is read from the generator**: `skill_id · source_game + skill · grammar · element treatment · response_class (strike / field / aura_loop / material) · mechanics {origin socket; aim rule; range / speed / radius / count / hop count; travel or ballistic params; active duration + tick schedule; termination} · presentation {primitive bindings; body extents in BH; phase envelopes; enabled layers} · provenance (source-game observation or Matt ruling per field)`. Aim rules: release-locked · owner-tracking · ground-locked · target-tracking · event-linked. The renderer never selects targets or infers grammar from a name; the fixture supplies hits, targets and expiry through the same interface a game would.

| Skill | Grammar | Treatment | Response | Mechanics to enter (from the source game) |
|---|---|---|---|---|
| Frozen Orb (D2) | **G1 projectile** + scheduled child emission (pooled bolt children; shards on expiry) | ice | strike | speed, range, emission schedule, shard count, expiry radius |
| Blackwater Cocktail (GD) | **G2 thrown arc → ground field** | fire + **material flask** | material → field | apex/flight time, target range, pool radius, burn duration, tick |
| Poisonous Concoction (PoE) | **G2 thrown arc → ground field** | poison + material flask | material → field | as above; cloud vs pool density |
| Lightning Blast (LE) | **G3 instant bolt / chain** (1 hop) | lightning | strike | instant, range, width, optional chain count |
| Zeus chain (Hades) | **G3 instant bolt / chain** (N hops) | lightning (Hades dialect) | strike per hop | hop count, hop delay, link lifetime, target order = events |
| Healing Hands (LE) | **G4 self-aura loop** | holy | aura_loop (support preset) | radius, duration, pulse period, stack/refresh |

### 2.2 Contract II — four runtime grammars (the time owner)

Grammar = a Godot 2D template: a timeline of events (anticipation → onset → peak → decay → residue, or activation → active ticks → deactivation) moving painted primitives with engine transforms, driven by an **effect-age clock + event timestamps** (shader `TIME` is not a lifecycle clock). Direction is runtime rotation, never baked facings. *(`corpus.db`'s 18 motion signatures / 27 archetypes are a naming reference, not a constraint.)*

| Grammar | The one moving thing | Time band | Dial / implementation |
|---|---|---|---|
| **G1 Projectile (+ emitter)** | a head that translates + a trail that lags; optional scheduled child emissions | `strike_fast_v1` at confirmed contact | runtime — pooled head sprite (optional 3–4-frame boil loop), `Line2D`/ribbon trail; ⟲ children pooled, **not** GPU sub-emitters; **burst interior = flipbook** |
| **G2 Thrown arc → field** | `screen = project(ground(t)) − up·height(t)`; landing accent; then a decal + a loop breathing for a fixed duration | ballistic + landing + `field_v1` (**to be measured**) | runtime; flask = upright RGB material sprite, tilt ≤ 10°, no tumble unless commissioned |
| **G3 Instant bolt / chain** | a link primitive drawn N times between N event-supplied point pairs (N = 1 = single bolt) | event-driven; `strike_fast_v1` per contact, centrally budgeted | runtime, necessarily; endpoint strips restored by tooling |
| **G4 Self-aura loop** | owner-anchored ring/dome loop + floor light; pulse per tick | `aura_loop_v1` (**to be measured**) | runtime loop |

**The dial rule** (probe 2): *bake a flipbook where the shape changes internally and the duration is fixed; compose at runtime where extent, direction, count or duration vary.* ⟲ Baking records existing motion; it cannot manufacture missing advection or breakup — an internally changing source must exist first. Bake with an **effect-only visibility configuration** (`transparent_bg` clears the viewport, not the terrain, Keeper or dummies); keep floor light, victim tint, hit-stop and shake live; verify **two repeated bakes match** (fixed seed + recorded events, clocks, RNG, warm-up, frame-zero policy, engine/renderer version) and that the baked layer reconstructs over **multiple backgrounds**, not only its original ground.

**Time bands:** `strike_fast_v1` (Hades, measured: peak 0–1 frames, half in 2–7, residue 0.3–1.0 s) and `strike_splash_v1` exist; **`field_v1` and `aura_loop_v1` must be measured** (their own lap) — until then, named Matt-approved fixture envelopes labelled provisional. ⟲ This dissolves the deferred "hybrid oracle" (R-C3-118/120): Hades strike bands + CoM/Slormancer legibility rules, each **scoped by class**.

**The invariant layer stack — shared implementations, not every switch on:** body (index-tinted through the shared `ShaderMaterial`) · halo · floor light (`PointLight2D`) · dark duplicate (same sheet, MIX black — an *approved per-preset option*; ⟲ its cost is ground occlusion and register, not headroom) · contact flash ≤ 0.1 s (strong strikes only) · residual decal · centrally arbitrated hit-stop/shake · victim tint. Presets: ordinary strike (flash off) · strong strike · field/aura tick (flash, hit-stop, shake, dark duplicate **off**) · healing tick (no white flash, scorch, shake, hit-stop) · material object (alpha-blended; lit by separate emission). **No second effect system** (Effekseer rejected). ⟲ E0 compares the normal preset *without* the dark duplicate against the exception, so the architecture is not passed on an exception its default omits.

### 2.2b Video as the burst-interior motion source (Matt's question, 2026-09-15 — the character-lane chain applied to effects)

Matt: *"Could it be that we need to start with a video as we ended up doing with the character so that Astra can break it down into frames and edit them?"* The answer splits by class, and the split is the dial rule itself:

- **Not for grammar, targeting or duration.** A chain hops to targets that exist only at cast time; a pool burns for a rolled duration; a projectile travels a runtime distance — a 6-second clip carries none of that, and an effect *is* its transparency, so the plate key that saved the character (an opaque silhouette on green) fails on glow and gas (probe 2 § 1.3). Video is not a shipping frame source for the whole effect.
- **Probably yes for burst interiors** — impact shatter, nova, flame breakup, pool ignition: the class where the dial already says "bake a flipbook because the shape changes internally and the duration is fixed." ⟲ The red-team's own gap: *baking records existing motion; it cannot manufacture missing advection or breakup.* Procedural can move a painted tongue, not make fire advect; the image model can paint the peak, not sequence. **The character-lane chain fills exactly this:** Astra paints the peak body on a plate → Grok i2v animates the burst (6 s / 24 fps / 145 frames; one burst ≈ 10–30 frames) → `oracle/video_cut.py` finds the single peak and decimates 24 → 12 → matte (plate key or signed cut) → **Astra re-skins cut frames with pose held** (the Q75 LABEL/edit mechanism) only where the video's register drifts → quantise to the index palette → flipbook, tinted per element like any other sheet.
- **What stays runtime even then:** the 0–1-frame onset (a runtime flash — 24 fps cannot represent 17 ms), placement, rotation, ground squash, the layer stack, and every parameter.

**Unknowns the probe must answer (kill criteria pre-registered):** (1) plate survival around an *emissive* subject — the Keeper's `#00ff00` held at 0.95–0.99; a burst's own glow bleeds into the plate (kill: matte halo > 1 native px after trim); (2) a clean single peak with no internal cut (kill: O1 double-peak, as R-C3-19); (3) frame-to-frame boil (kill: O8 unique-frame change rate above the band; hue SD pulsing beyond O4); (4) decay resolvable at 24 fps (2–7 strike frames = 80–300 ms = 2–7 video frames: marginal; field/pool ignition at 0.3–1 s is comfortable); (5) per-frame re-skin cost (kill: > ~12 edits per burst — the alphabet costs ~30 images for everything); (6) the Q75 re-skin mechanism itself, still unvalidated on the character (a burst re-skin that survives the identity gate would validate both).

**Cost:** one Grok clip per probe (T30 done; balance needs a top-up — H-C3-1; ~$0.42/clip) + ≤ 4 Astra edits. **If it passes:** the dial's "bake a flipbook" source for bursts becomes video-derived rather than procedural-baked, Astra's role for that class becomes per-frame stylist, and the burst interior stops being the weakest link of the alphabet route. **If it fails:** bursts fall back to 3–5 painted key states over tooling-transformed guides (Astra S1 § 2b conditions) — the authored-key-state exit already pre-registered at E1.

### 2.3 Contract III — the painted primitive alphabet (the still owner)

**Scale contract:** Keeper = 130 screen px = 1 BH; effect art step **3 screen px** (Matt rules it in motion at E1); 64 native px ≈ 1.5 BH; a 3–6 BH burst = 130–260 native px of *assembled* extent, never a silently enlarged brush. Camera yaw 47° / pitch 52.95° in calibration; **0.58 ground squash once, to unprojected ground geometry only**; ground rotation before projection; upright bodies never squashed; ⟲ a screen-projected ground paint-over is either constrained in use or gets a separately authored unprojected production asset — "do not squash twice" does not license arbitrary rotation.

**Encoding:** greyscale **value-index + independent alpha** (index 0 may be opaque; no threshold makes dark pixels transparent; `white_core_keep` removed; ⟲ the four-band palette lookup is a `ShaderMaterial`, not a multiply — do not premultiply index values before lookup); RGB + material palette only for the flasks. **Light rule:** emissive bodies self-lit (rotation must not rotate a painted highlight); material objects scene-lit, rotation restricted; ambient planes for shards.

**Build list** (slots, not a purchase order — ⟲ commission only what the current fixture needs):

| Painted shared (8 + 1) | Procedural / derived |
|---|---|
| P01 head/core 128² · P02 tapered streak/wisp 192×128 · P03 field body 256² · P04 residue/decal 256² · P05 chain link 192×128 · P06 broken ring segment 256² · P07 wedge/impact tooth 128² · S01 bounded puff 128² (density + coverage) | S02 mote/spark 16² · C1 flash mask · C2 halo/floor-light mask · C4 dark duplicate (source alpha) · C5 victim tint (no asset) |

Per-element additions, 2–4 each, on profiles T tongue/petal · J junction/crown · D density puff · M flask (RGB, scene-lit) · R shard/husk · G seal/patch · W long wisp/prong: **fire** hooked tongue, oil flask · **ice** faceted shard, broken frost crown, angular puff · **poison** viscous lobe, lobed puff, poison flask (derived) · **lightning** branch junction, needle prong · **holy** folded ray/petal, interrupted seal. Flasks belong to the two thrown skills. ~12 unique painted assets per treatment is a **review trigger**, never permission or a cap (Hades per-god median 12.5, range 4–26).

**Anchor package ("VFX chunk_A"):** three approved constructions — directional (G1), radial (contact burst), ground-bound (G2 field) — each as a paint-over of a *runtime blockout instant over the real scene*, the isolated registered quantised native body, and a nearest enlargement; plus tool-assembled layer-stack, scale/attachment and palette/roles boards (17 images; a production brief receives **three**). ⟲ **The first fire paint-over is provisional; the anchor is established by E1's recomposed *moving* result**, and later additions are compared against the **fixed original anchor and the nearest sibling**, never only the latest descendant. Elements 2–5 begin as tool-recoloured versions of the same constructions, then receive their distinctive silhouettes; ⟲ distinguishability without glow is tested **unlabeled, at actual size, in mixed casts, across all treatment pairs** (fire/ice is an easy pair; fire/poison and holy/lightning are the test), with a common-palette diagnostic to show shape/motion carries identity. Bootstrap: fire (G1) → ice → poison → lightning → holy.

**Brief discipline** (three complete templates in `02c-` § 6: fire tongue, chain link, blockout paint-over): one production primitive per call; one edit objective; one diagnosed retry then change representation; three images with stated roles; asset role stated first; exporter responsibilities stated; retry criteria on usefulness. Never ask for exact RGB, alpha topology, twelve frames from percentages, a matte across mixed material, or a runtime fix by more emphatic prose. Haze fix is representational — *"paint the opaque banded body representing the emission; light spill is a runtime layer"* — not a plate colour. ⟲ Every isolation and EDIT counts against the image cap.

**Extraction contract:** genuine RGBA first, channel-inspected (≥ 99 % of an **independently declared** interior mask at α ≥ 0.98; ≤ 1 native-px fringe over black/white/dirt/foliage); fallback = one diagnosed EDIT onto a flat key plate + deterministic keying (⟲ unproved until exercised once); if both fail, split the asset. ⟲ **Capture contract for guides** (step 3): at one frozen scene state capture a *clean plate* (effect + world responses off), the *grey guide* (body on, flash/halo/floor light off), *masks* (editable region, body coverage, primitive IDs, protected foreground occluders), a *manifest* (tick/event state, seeds, hashes, viewport, camera, crop origin, native↔screen transform, pivot, attachments, plane/projection, sampling + colour space) and a *separate annotation board*. Restore protected pixels **from the clean plate** (including pixels revealed inside new holes); preserve foreground occlusion separately. Straight-alpha PNG at interchange; premultiply once *only if* the runtime path is premultiplied. Report raw model compliance and exporter-enforced compliance separately; success after unlimited repair does not validate the budget.

## 3. The loop

⟲ **Prerequisites (before E0, outside every burst estimate):** drax builds one reusable **G1 event-driven production component** (release / contact / cancel interface; effect-age clock; grey/painted material substitution) and a **deterministic fixture host** (Keeper, one dummy, real ground, reset-and-replay to a chosen tick — a GPU particle sim is not made seekable by a scrubber); pin the installed Godot version; lock **Compatibility + browser parity** as the acceptance platform. The fixture *instantiates* the component; debug UI does not become runtime architecture. TOOLING stays serial; E1's ≤ 40-min burst covers only the named exporter amendment.

Adding a later skill to a proven grammar: spec → preview with existing assets → fill a genuine alphabet gap only if existing primitives cannot express the distinction (normally **zero images**) → regress against tripwires **and the frozen cross-family reference set** (§ 4).

## 4. Coherence QA

Three measured outputs — body/coverage, light-only, final composite — the oracle consuming runtime coverage masks. Class gates: strike vs the named Hades subtype; field boundary ≤ 10 %, activation/expiry within one tick, no residue presented as hazard; aura attachment ≤ 1 native px, no drift, calm-loop area modulation ≤ 15 %. **After-compositing white:** `V > 0.95 ∧ S < 0.20`; ⟲ report **total crop coverage, baseline coverage and VFX-attributable white separately** — never subtract silently; gate ≤ 2 % of the crop at four simultaneous casts, and if the clean background itself exceeds 2 % rule a separate attributable-VFX budget. Halo/floor lifts (+.16–.41 / +.07–.09) are reference observations — on ochre choose the lower safe gain.

**Matt's fixture, every effect:** bright dirt + foliage; one cast; four casts synchronised + staggered; Keeper walking through; a dummy overlapping the ground body; body-only toggle; eight directions; cold first cast, repeat, cancel. Rulings: *same world · grammar reads before the glow · element identifiable · large enough without obscuring the fight · world response adds weight · painted planes, not stretched stickers.*

⟲ **The failure mode most expected (Astra S3 § 5): approved local exceptions accumulating into global drift** — each treatment judged against its nearest recent parent, every approval defensible, the library no longer one thing by month six. The tripwire: **a frozen cross-family reference set** (original anchor versions, approved parameter envelopes, comparison captures) and **mixed-vintage playback of every new effect with old ones** on every addition; a shared-preset change reruns all affected fixtures. Plus: new palette / art step / material mode / layer preset; > ±15 % deformation of a reusable primitive; exceeds the approved BH or light envelope; adds white via overlap; needs recurring flash to read; a one-off asset without a demonstrated gap; passes a still but fails direction changes or four-cast playback; four-cast frame time +2 ms p95 against a **stated target frame rate** on the Mac mini and in the browser. **Failure priority when register, density and performance conflict: body/footprint readability first, secondary glow and particles second.**
