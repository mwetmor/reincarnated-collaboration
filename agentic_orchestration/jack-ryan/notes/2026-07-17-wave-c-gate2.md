### 7. DISCIPLINE CANDIDATE — RATIFIED as Discipline #62

**"Parallel same-tree agent hygiene"** ratified as engineering-disciplines.md Discipline #62. Two-clause form:
- **(a) Stage by explicit pathspec ONLY** — no `git add -A`, no `git add .`, no `git commit -a` when a parallel teammate is authoring in the same working tree. Contamination protection.
- **(b) NEVER rewrite (amend/reset) a minted commit once it exists** — a parallel teammate may have tagged or built on it. Contamination cleanup = a NEW commit (`git commit` with the fix), not a rewrite (`amend`/`reset`). Tag-durability protection.

**Evidence base:**
- 2026-07-17 Wave-C: rocket's `git add -A` in support-hygiene slice swept gamora's uncommitted geometry smoke → contamination (VIOLATES (a)). Rocket's `commit --amend` rewrote `f64e489` → `f0c1734` after gamora had already tagged `v1.10-wavec-3` at `f64e489` → orphaned tag reference (VIOLATES (b)). Repair required a new commit (`5cd97a2`) + tag re-point — the correct pattern.
- 2026-07-16 Wave-B: same pattern held by luck only (no gamora work in-flight during rocket's Wave-B slices, so the risk didn't materialize).
