## Concerns dispositioned

### C1: Bimodal roster artifact vs math-note prediction gap

The math note §4.2 estimated specific modifier values (shadow ~0.38, water/earth ~0.13) that don't match the actual roster's distribution (bimodal gap 0.34–0.63 empty). This is not a math-note defect — the note's acceptance criteria (§5.2) did not require per-archetype accuracy, only primary-criterion pass and floor-break for ≥5 of 10 kits. The prediction gap is documented in AGENT_STATE.md. No action required for W0.10.

**Routing:** INFO to knight-rider — the P1 convergence sweep will use a fresh roster with converged modifiers; the bimodal artifact may naturally dissolve. If it persists, Discipline #17 anomaly-count refinement is a P1 discussion item.

### C2: Anomaly-count metric insensitivity to bimodal distributions

50/50 anomaly count in both W0.9.6 and W0.10.5 does not reflect the genuine improvement (2 kits exited the floor). The metric conflates "all anomalous" with "still anomalous for different reasons." A refined metric (per-tier pass-count or exit-count) would be more useful.

**Routing:** INFO to knight-rider for P1 Discipline #17 refinement scope. Not a W0.10 blocker.

### C3: Convergence-path NullWriter (long-term)

The deliberate split (validation-path wired, convergence-path NullWriter) is correctly documented in v1.29. The long-term architectural question of whether production convergence runs should emit spatial telemetry remains open.

**Routing:** P1 scope per MIGRATION.md v1.29. No action for W0.10.

### C4: Gandalf A3 documentation lift

Encounter-configurable-leash principle not yet lifted to engineering-disciplines.md or a canonical story doc. This is the only open item from Phase 1.5 amendments.

**Routing:** knight-rider follow-on task, post-W0.10 ratification. Not a blocker. *(Per gandalf close-out: PARKED until second encounter-configurable instance arrives, likely P1/P2 — "one instance is not a principle".)*
