## Why this archive exists

Yomi was generated as a one-off side-seed pass against the canonical engine on 2026-05-13 to give drax real season data for v0.5-real-gear loadout-app work. The engine-side artifacts (`seasons/season_002328/`, telemetry rows) existed at generation time and through the 2026-05-14 23:58 v1.1 gear_pool re-export, then were deleted at some point before this audit (2026-05-16). The provenance audit (referenced above) reconstructs the full timeline.

By the time this archive lands, the loadout repo SPOF has already been closed via Option 2 (push to `https://github.com/mwetmor/reincarnated-loadout`, 2026-05-16). This archive provides the **fourth** redundancy layer — matching the four-deep standard established by the research.db retirement (working tree + local git + remote + elrond archive). It also gives gandalf, drax, and engine pipeline a stable file-system referent for design discussions that name Yomi (Lantern-Keeper, Pomegranate, Izanami Passage, miasma/lantern/brine/bone elements) independent of loadout app evolution.

## Notes on what is NOT in this archive

The archive captures the **consumed working shape** as currently used by the loadout app (the engine internal `manifest_version: 1.3` shape with per-class JSON tree + the export-shape `gear_pool.json` v1.1). It does **not** include:

- **Engine-side telemetry rows for season_002328.** Those existed at generation time but were deleted from `data/telemetry.db` along with the `seasons/season_002328/` directory after 2026-05-14 23:58. Per the provenance audit § 4, these are not reproducible byte-for-byte from seed=2328 against current engine code (post-B10.4 swarm calibration shifts).
- **`seasons/season_002328/gear/catalog.json`.** This was the input to the deterministic gear-pool replay (per `reincarnated-engine/src/reincarnated/export/MIGRATION.md` v1.1 § "How stats are derived"). It existed at re-export time and was deleted with the rest of the directory. The fully-resolved gear_pool.json IS preserved, so re-derivation of stats from the catalog is not required — the values already live in the archive.
- **Trial boss data.** Not present in the loadout source (loadout doesn't consume trial data). The original engine-side `trial.json` is lost.
- **Monsters JSON / monster definitions.** Not present in the loadout source. Lost.
- **`fights.jsonl` (per-fight log).** Not present. Lost.

For the design-vocabulary purpose this archive serves (preserving the named classes, anchor metadata, element selections, and gear pool that gandalf / drax / docs reference), this scope is sufficient. For full-engine-state recovery — telemetry, fights, trial, monsters — the only path is a fresh re-run from seed=2328, which per § 4 of the provenance audit produces **A** Yomi (different stats due to engine code changes) but not **THIS** Yomi.
