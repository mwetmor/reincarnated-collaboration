### RF-4: di-spiritform-druid-pvp — "spirit form" is not a confirmed named skill
Druid class (launched July 3 2025) skills fetched from Blizzard official: transformations = Werewolf / Werebear / Stag; summons = Wolves/Grizzly/Oak Sage/Ravens. "Spirit form" appears nowhere in official skill list or PvP forum complaints. Druid PvP complaint posts confirm Druid dominates PvP (forum thread Sep 2025: "Even after the nerf druid seems unkillable") but no "spirit form" skill is named. The negative_canon_target claim about "spirit-form silence/CC suite" is UNSUPPORTED — the complaint mechanics appear to be healing/damage-reduction/sustained-denial (not silence). **This is a D-2a structural flag: the negative kit's defining mechanic label may be a fabrication. Recommend steward review whether this kit should be re-labeled per actual Druid PvP mechanics (e.g., Werewolf sustained-denial, armor stacking, idol pressure).**

### RF-5: DI resource naming — consistent UNSUPPORTED pattern across 8 kits
Barbarian Fury, Monk Spirit, DH Hatred, Wizard Arcane Power, Necromancer Essence are all recorded in DB as class resources but NONE were explicitly named as such in fetched DI-specific guide text for this batch (guides refer generically to "energy"). This is a documentation-gap issue in DI guides, not necessarily DB errors — these resource names are plausibly correct by analogy with D3 (DI launched with the same six D3 classes). Steward should decide whether to accept prior-informed labels as OK for DI launch classes or require fetched confirmation. Batch records these as UNSUPPORTED per protocol; DB conf values (0.72–0.82) reflect appropriate uncertainty.

### RF-6: di-tempest Mist Touched terminology — "clones" vs "shades"

Mechanically similar to clones but the in-game terminology is "Zephyr/Mist-Touched Orb," not "clone." Community guides also use "Zephyr." Not a structural contradiction but worth noting for canonical labeling accuracy.
