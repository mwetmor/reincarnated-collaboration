## Red flags (erratum queue)

1. **d2-fishyzon — spec core_skills error (HIGH PRIORITY).** Spec records `["Guided Arrow", "Valkyrie"]` but fetched text across multiple sources (Silverbolt blogpost, diablo2.io forum, search aggregations citing Nightfish's original guide) consistently defines Fishyzon as LF/CS/FA (Lightning Fury + Charged Strike + Freezing Arrow). The spec aliases also appear wrong: "Valkyrie Amazon" and "Guided Arrow Valkyrie build" describe a different archetype. This is a kb-derived probe artifact error propagated into the spec. Erratum candidate.

2. **d2-ghost-pvp — Whirlwind access mechanism unclear.** Whirlwind is canonically a Barbarian skill. Assassins do not have native Whirlwind in their skill tree. The Ghost Assassin appears to access WW via a specific mechanism not fully clarified in fetched text (possibly via claw skills or a specific item interaction). The mbaker wixsite guide treats this as assumed knowledge. Recommend steward confirm the WW access mechanism for the Ghost Assassin (e.g., through a specific runeword or game mechanic); flag for mechanics depth check.

3. **d2-fury-wolf — Metamorphosis unique (possible RotW-era item).** The S14 Maxroll guide for Fury Druid lists "Metamorphosis" as a helm option. This item does not appear in pre-RotW D2R item lists in my knowledge. If Metamorphosis is a RotW-era new unique, it should not be back-attributed to the `lod` era claim. Item is noted in dossier but not affecting era verdicts.

4. **d2-firewall-sorc — Wayback URLs not crawlable.** web.archive.org returned "unable to fetch" error in this environment. The lod-1.09 era claim was confirmed via the Moving Caravan community forum (which explicitly discusses 1.09 meta builds including Fire Wall as "single highest damaging skill in 1.09") rather than an Arreat Summit Wayback snapshot. Wayback attestation not achieved for this kit; era verdict CONFIRMED via alternate source but Wayback instrument log is negative.

5. **rotw-s14 token confirmed as "Reign of the Warlock."** RotW = "Reign of the Warlock" expansion for D2R; Seasons 13-14. Season 14 launched May 22, 2026 with Patch 3.2. Post-cutoff token — all rotw-s14 era verdicts based on fetched text only (confirmed: d2-fire-sorc, d2-frozen-orb-sorc both have Season 14 Maxroll guide attestation).
