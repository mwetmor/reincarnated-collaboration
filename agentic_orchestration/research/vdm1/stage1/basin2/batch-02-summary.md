## Red flags for steward

1. **4 kits with D-2a era floor contradictions**: gd-fire-strike-purifier, gd-forcewave-warlord, gd-mortar-purifier, gd-panettis-mage-hunter. All share the same root cause: base-2016 era floor stamped on a class combination requiring an expansion mastery. Elrond ERRATA recommended on all four — floor should be corrected to aom-2017 (Inquisitor kits) or fg-2019 (Oathkeeper kits). Note that the underlying *skills* (Fire Strike, Mortar Trap, Forcewave) are base-game Soldier/Demolitionist skills — the error is in the *class combination* era, not the skill debut era.

2. **gd-panettis-mage-hunter element=lightning**: PRM is tri-elemental at base (1/3 each fire/cold/lightning). The `lightning` label likely reflects a historical build bias toward lightning-converted PRM variants, not the skill's canonical base. The ailment `shock` is a downstream artifact of this misclassification. Both fields should be corrected; `mixed` or `elemental` is more accurate for the base skill.

3. **gd-pet-conjurer Call of the Grave**: A clear data-entry error — the Necromancer skill was likely confused with the Shaman's Call of the Beast. No Conjurer build in the corpus uses or references Call of the Grave. Elrond correction: remove from core_skills, optionally note Call of the Beast as the correct Shaman analog.

4. **gd-fire-strike-purifier economy**: `spirit/focus / meter` is the wrong model for a default attack replacer. The resource is `energy` spent per WPS proc, effectively making it attack-speed-gated rather than meter-gated. The `spirit` label may be a confusion with the stat name in GD (which is called "Spirit" as a stat, not as a resource pool). Correct economy model is `energy / attack-replacer`.
