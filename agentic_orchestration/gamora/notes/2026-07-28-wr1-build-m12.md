## §3 — ⛔ THE HALT: the spec's required oracle disagrees with the spec's operator

R-M2-4 makes the discrete 16-ray oracle `n(r)`'s falsifier and pre-registers the consequence:
*"Agreement tolerance ≤ 5 % or the operator is wrong and §5.2's whole table with it."* I built it
exactly as specified — 16 rays at 22.5°, blast 1.5, segment 12.0, coverage of a point target,
36,000 uniform azimuths — and it agrees at **no** radius under **either** count convention:

| r (m) | analytic `n(r)` | oracle MEAN | oracle min–max | dev vs mean | dev vs max |
|---|---|---|---|---|---|
| 1.0 | 8.6394 | **16.0000** | 16–16 | **−46.0 %** | −46.0 % |
| 2.0 | 4.8197 | 4.3196 | 4–5 | +11.6 % | −3.6 % |
| 2.5 | 4.0558 | 3.2769 | 3–4 | +23.8 % | +1.4 % |
| 5.0 | 2.5279 | 1.5516 | 1–2 | **+62.9 %** | +26.4 % |
| 9.0 | 1.8488 | 0.8529 | **0**–1 | **+116.8 %** | +84.9 % |
| 12.0 | 1.6366 | 0.6387 | **0**–1 | **+156.3 %** | +63.7 % |

**Mechanism (arithmetic, not opinion).** For spokes of angular spacing `S` and a coverage window of
width `W`, the expected count over a uniform target azimuth is **exactly `W/S`** and the maximum is
`⌊W/S⌋+1`. EXT §1.3's operator is `W/S + 1` under a small-angle approximation — **the
maximum-count formula, labelled as an expectation.** It overstates the mean by ≈1 projectile
wherever the window is small, and *understates* below 1.5 m where the target is inside the launch
point's blast and all sixteen cover it.

**The load-bearing half.** The `+1` asserts a floor of one projectile. That floor is geometrically
true only inside **7.69 m** (exact segment-distance boundary; EXT's quoted 7.64 uses the arc
approximation). At `r = 9` and `r = 12` **the oracle's minimum is 0** — band 3 has gaps, and band 3
is exactly where the spec's `r = 9` reproduction (536.9) lives.

**Blast radius, stated honestly.** If the oracle mean is the truth, the composed death-2 model at
`r = 5` falls 524.3 → ≈322 delivered and no longer reaches the measured ≥ 541; at `r = 9`,
536.9 → ≈248. **The 541 reproduction — the spec's "single strongest validation available to either
spec" — is CONDITIONAL on the `+1`.**

**What I did.** Shipped the spec's operator **verbatim**. Did not tune it toward the oracle, did not
weaken the oracle toward it. R-M2-4's consequence clause is a **spec-level** consequence and
re-authoring the operator here would be this seam deciding a spec question after seeing which answer
flatters the reproduction. The oracle ships as a first-class function; the test
`test_T_M2_4_oracle_disagreement__SPEC_TOLERANCE_FAILS` **pins both tables and asserts the spec's
predicate in the negative**, so neither side can be silently moved toward the other and the
falsification cannot decay into a footnote. **Conductor's ruling, not mine.**

**Minor second divergence, named:** T-M2-2 expects `n(100) → 1.0`; the operator returns **1.0764**
(`1 + 7.639/r` approaches 1 asymptotically; the clamp is a FLOOR, never an equality). Asserted in
the form the operator can satisfy, and reported rather than hidden behind a loose tolerance.
