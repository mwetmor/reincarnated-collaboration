## Item 1 — WARN-1 guard ordering: CLOSED

**Source:** jack-ryan Gate-2 re-review `2026-07-28-gate2-gamora-dot-delivery-2-rereview.md` §WARN-1.

**Root cause (pinned, not guessed).** The C-5 banked-evidence guard was *correct and late*. It
lived inline at the report-write site in `src/reincarnated/simulation/spatial_gauntlet/kitcal_g5_harness.py`
`main` (pre-fix :1048) — which runs **after** `drive(...)`. But it is `run_one_fight` that
`mkdir`s `traces/` and writes one `.jsonl` per fight. So the guard printed REFUSED and returned
rc=2 with five orphan trace files already sitting inside the directory it exists to protect. The
accident class C-5 was chartered to make structurally impossible was still live one layer down.

**Fix — ordering, not policy.** The predicate is extracted as
`banked_evidence_refusal(report_path, this_hash, overwrite)` and called in `main` immediately
after `out_dir` / `trace_dir` / `report_path` are computed and **before** `drive`. Nothing emits
between argparse and that call, so a refusal now writes zero files and creates zero directories.
`_git_hash()` is a pure read, so the hash is available at that point without running anything.
A **second** call is retained at the write site as a last-moment re-check for the one case the
pre-check structurally cannot cover — a battery running tens of minutes while another process
banks a report at that path — reading the report's own stamp.

**Discipline #12 — explicitly NOT a semantic shift, and checked rather than asserted.** The
refusal *set* is byte-for-byte unchanged: same hash → proceed; `--overwrite` → proceed; report
absent/unreadable/either hash missing → proceed; different hash → refuse. Only the *moment*
moved. Conductor concurred and classified the landing non-kernel-touching (charter §8.1).
