## 2026-06-22 — Resist model pivots Path A → Path B (cap-everything-but-costly); anti-tax-unreachable guard superseded

**Decision**: The resist meta pivots from **Path A** (resist scarce — total roller resist capped ~1.60 < 2.0, capping *deliberately unreachable*, "bring the right form" = spike-matching one element) to **Path B** (resist is a **mandatory-but-costly baseline** — every endgame player is *expected* to reach ~0.75 on all 7 rotating elements; reaching it consumes ~the entire defensive gear budget, so capping genuinely **competes with offense for gear slots**). This is the D2-Hell / PoE-maps endgame model, native-adapted as **slot-competition** (not an imported difficulty-tier deficit). Design-of-record: `agentic_orchestration/gandalf/notes/2026-06-22-path-b-resist-design-spec.md`. Matt affirmed Path B 2026-06-22 and directed the spec be written on this basis.

The Path A anti-tax guard recorded at the typed-resistance G-C close (decisions-log `ea39ecc`; anchor ruling `2026-06-21-typed-resistance-boss-anchor-ruling.md`) — `N·r_hi < ~2.0`, production roller max total resist 1.60 < 2.0, capping more than 1–2 elements deliberately out of reach — is **SUPERSEDED**. Under Path B the safety condition is not "capping is unreachable" but **"capping is NECESSARY AND ACHIEVABLE within budget"** (necessary-but-achievable = genre standard; necessary-but-unachievable = the rejected PoE one-shot tax). The cost is paid in **slots** (~9 resist-capable slots, one resist affix each), not in an unreachable ceiling.

**What STANDS (explicitly not reopened by this pivot):**
- **Boss `damage_multiplier` = 5.0 @ cadence 4.5s, and swarm `damage_multiplier` = 0.20** — LOCKED at the anchor ruling, **unchanged**. Path B does **not** touch per-hit damage; it is a generation-budget + affix + sim-Loadout + monster-content change. The dm=6.0 rejection (PoE tax wearing a difficulty knob) still stands and is now reinforced: Path B achieves cost via slot-competition, removing any temptation to manufacture it via damage.
- **The resist formula and both caps** (0.95 clamp, 0.80 gear ceiling) — unchanged; no math-model work. The 0.80→0.95 overcap headroom, inert under Path A, is given purpose under Path B as the reduction-cycle buffer (spec §8).
- **All 7 elements every season** (no rotation/subset; `monster_generator.py:490`) and the **player-defender RAW / monster-defender floored asymmetry** (`combatant.py:926` / `:1104`) — unchanged.

**What COMPOSES (carried forward, not superseded):**
- The **soft-median watch-item disposition** (`2026-06-21-encounter-model-firm-up-disposition.md`) composes cleanly. The 0.926 unmatched survive+kill median is the **build-floor measured correctly**; the firm-up lever is the **dodge-skill ceiling** (architected, half-built, deferred behind Godot combat), NOT a floor re-tune. The dodge-ceiling remains the experiential texture **on top of the now-Path-B floor**. Path B changes *how the floor is built* (slot-competition capping, not spike-matching); it does not change the floor/ceiling split. The encounter-model telegraphed-signature-slam is the shared answer to both the solo §3.4 firm-up and the proxy §4 grading (disposition §65).

**Reasoning**: Recording per Review Principle #4 (decisions-log as truth) and Discipline #13 (record a deliberate pivot so the superseded design does not drift back in). Path A and Path B are **mutually exclusive resist philosophies** — Path A makes capping scarce and rewards spike-matching; Path B makes capping the expected baseline and relocates the threat to the rare/unique reduction monster that *strips* your cap. Matt affirmed the pivot deliberately after the cap-everything-vs-spiky fork (`2026-06-22-cap-everything-vs-spiky-resist-fork.md`) and Legolas's D2/PoE endgame research (`legolas/findings/2026-06-22-d2-poe-endgame-resist-and-monster-modifiers.md`). The pivot is recorded as a foundation change, not a drift, precisely so the spiky/anti-tax design is not reintroduced by inertia in a later wave.

**Alternatives considered**:
- **Keep Path A (spiky / anti-tax, scarce resist):** REJECTED by Matt — the spike-matching threat model ("bring the right form" = the one element you didn't build) is thinner than the D2/PoE-proven slot-competition model, and the anti-tax-unreachable guard left the 0.80→0.95 overcap headroom and the whole itemization-richness axis inert. Path B preserves genuine itemization choice (uniform-under-cap / concentrated-cap-some / full-cap) that Path A collapsed to a single shape.
- **Manufacture Path B's cost via a D2/PoE baseline deficit (−100/−60 starting penalty climbed out of):** REJECTED in the spec (§2) — that deficit is an artifact of difficulty tiers (Normal→NM→Hell) we do not have; importing it is gratuitous. Native slot-competition (resist starts at 0; budget tuned so uniform-capping consumes ~the whole defensive budget) yields the identical opportunity cost via a native mechanism.
- **Raise budget without the breadth-affix + reduction-cycle pieces:** REJECTED as a partial build — high budget + no breadth affix = unachievable mandate = the tax; high budget + no reduction cycle = solved, boring baseline. Path B is load-bearing on three pieces that must ship together (spec §9); shipping a subset rebuilds the tax.
