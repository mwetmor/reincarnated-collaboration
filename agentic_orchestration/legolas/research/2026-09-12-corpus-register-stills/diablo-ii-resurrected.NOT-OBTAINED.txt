WHY THE SLOT IS EMPTY
---------------------
Full-resolution download is authentication-gated. Two independent routes tried:
  1. The blob path the page exposes —
     https://blizzard.gamespress.com/blob/BlizzardLive/2021/09/23153209-24f49909-1bd8-4200-b846-75251129710b/DIA_16890_D2R_LaunchScreenshots_001.png
     returns an HTML error page: "This type of page is not served."
  2. The CDN path (imguscdn.gamespress.com) serves ONLY the exact signed
     query string embedded in the page, which is pinned to w=250:
        ...?w=250&mode=max&otf=y&quality=90&format=jpg&bgcolor=black&sky=<token>
     That URL returns a real JPEG — but 250 x 141 px.
     Altering w to 1600 / 3840, or dropping w, invalidates the signature and
     returns, verbatim:
        "You are not authorized to access the given resource."
  The page's real download mechanism is a POST to /Files/Zip behind a
  [ Log in ] control — i.e. Blizzard Press Center registration.

A 250 x 141 thumbnail was NOT saved as the deliverable. At that size the
player character is ~10 px tall, which is useless for the scale calibration
this commission exists to serve, and it is a CDN derivative rather than the
press asset. Recording the gap is the honest result.
