## URL pattern note
All 88 IAU constellation boundary diagrams follow the pattern:
`https://upload.wikimedia.org/wikipedia/commons/[hash]/[ConstellationName]_IAU.svg`

The hash can be found via the file page at:
`https://commons.wikimedia.org/wiki/File:[ConstellationName]_IAU.svg`
