## Primary image type: Wikipedia IAU constellation boundary maps

Each IAU constellation has a Wikipedia page at `https://en.wikipedia.org/wiki/[Name]_(constellation)` (or `https://en.wikipedia.org/wiki/[Name]` for major constellations). Each page contains the official IAU constellation boundary map with:
- The constellation figure (line drawing)
- Blue-filled polygon showing IAU boundary
- Star positions with Bayer designations
- Source credit: IAU / Roger Sinnott & Rick Fienberg / Sky & Telescope (for the colored versions)
- License: **Public Domain** for the base IAU maps

Pattern used in corpus: `image_url: "https://en.wikipedia.org/wiki/[Constellation]_(constellation)"` — pointing to Wikipedia page (which contains the map), not to the specific file URL. Phase 2 can retrieve exact `File:XxxCC.jpg` URLs from each page.

## Southern Hemisphere Milky Way / Atlas image

For IAU constellations covering the Milky Way core region (Sagittarius, Scorpius, Centaurus, Crux):
- ESO/S. Brunier, *The Milky Way Panorama* (CC-BY 4.0): https://www.eso.org/public/images/eso0932a/
- NASA APOD images often capture constellation-specific Milky Way views (check https://apod.nasa.gov/)

## Star identification images

For alpha stars with notable appearances:
- Sirius (α CMa): Hubble white-dwarf companion visible in HST image
- Betelgeuse (α Ori): ESO surface-resolved image (VLT SPHERE, 2020)
- Antares (α Sco): ESO surface-resolved image (AMBER/VLTI)
- Vega (α Lyr): NASA artist concept for exozodiacal dust disk
- Canopus (α Car): USAF GEODSS image (Canopus as navigation star)
