{{Intro}}
*{{Mb|=Faster Run/Walk}} from items increases walk and run speed (but not [[Charge]] speed). However, unlike other velocity modifiers it is not applied directly, but subject to diminishing returns:


:Effective Faster Run/Walk = [ (150 * FR/W) / (150 + FR/W) ] [https://www.lurkerlounge.com/forums/thread-11997-post-1655.html#pid1655]


*For example, 100 FR/W only increases walk speed by 60%, not 100% [ (150*100) / (150+100) ]; 200 FR/W only increases walk speed by 85%, not 200% [ (150*200) / (150+200) ].
*FR/W required to achieve a specific velocity or EFR/W bonus can be calculated as follows:


:FR/W = { (150 * EFR/W) / (150 - EFR/W) }


*For example, to increase walk speed by 100% requires 300% FR/W { (150*100) / (150-100) }.
*Every 1% EFR/W increases walk and run speeds by 0.06 yards per second, although FR/W alone can never apply a velocity bonus equal to or greater than 150%. Conversion tables for FR/W and EFR/W are below.
