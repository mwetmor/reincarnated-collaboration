## CRITICAL SYSTEM FINDING — Class Engravings Removed February 2025

> **POST-CUTOFF LAW flag: system rename event confirmed from live sources.**

**The class engraving system was entirely removed February 26, 2025**, as part of the "Call of the Wildsoul" update. The official announcement states: *"Class Engravings have been removed and replaced with Ark Passive Enlightenment Effects."* Players with existing Class Engraving Books received exchange tokens valid until August 27, 2025.

**What this means for the harvest:**

1. **Identity fork names are PRESERVED.** The Enlightenment tree for each class contains the same identity names as the old engravings (Mayhem, Reflux, Igniter, Gravity Training, etc.) as node names within two branching paths. Community continues using engraving vocabulary to refer to these paths colloquially. The MECHANICAL IDENTITY persists; the delivery mechanism changed.

2. **New delivery mechanism.** Identity paths now expressed through the Ark Passive Enlightenment tree (class-specific subtree, unlocks at IL 1100, max 92 points, prerequisite-gated node acquisition). Gear-slotted engraving books/accessories are replaced by passive tree node allocation.

3. **New confound dimension.** IL 1100 gate for Enlightenment = new level of the honing-economy confound (HONING-ECONOMY CONFOUND LAW). Identity is now progression-locked as well as gear-honing-indexed. Rows carry `il_confound: true` for this reason.

4. **Newer classes** (Wildsoul, Guardianknight, Dragonknight): Built natively on Ark Passive system. Their identity forks may not have legacy engraving names — they may use purely new vocabulary. Flags: `legacy_engraving_system: false` on these rows.

5. **Folk name vocabulary.** Commission kit_id uses `la-<class>-<engraving-slug>`. The engraving slugs are the FORMER class engraving names (Mayhem, Reflux, etc.) which now refer to Enlightenment path identities. This preserves community vocabulary and continuity with the pull tranche's la-prefix rows.

**Source:** https://www.playlostark.com/en-us/game/releases/call-of-the-wildsoul (fetched 2026-07-15)

### MECHANICS-GAP CENSUS (rolled up from rows)

Notable gaps between LA vocabulary and current engine vocabulary:
1. **Tripod system** — LA's skill upgrade tree (3-tier, 3 options per tier) creates conditional skill behaviors not representable in our skill_tags vocabulary. Tripods can change delivery type, add ailments, extend range — this is a meta-level on top of skill identity.
2. **Identity gauge as 3-phase resource** — LA gauges often have BUILDER phase (blue skills) → READY STATE → SPEND phase (purple skills) + IDENTITY ACTIVATION (Z key). Our economy schema captures spend/meter/builder but the 3-phase sequencing with manual activation is richer.
3. **Stagger System** — LA has formal Stagger ratings (Low/Mid/High/Highest) per skill. Our engine has no stagger axis. Highly genre-relevant for boss design.
4. **Destruction/Part Break** — LA has formal Part Break system (destroys specific monster parts). No equivalent in engine. Mentioned in pull tranche; confirmed across multiple classes.
5. **Awakening Skills** — each class has 1-2 Awakening skills (ultra-high-damage, long-cooldown "limit break" equivalents). Not captured in our kit-identity vocabulary.
6. **Back-attack vs Positional system** — LA's back-attack mechanic (+10% crit rate, +5% damage from back) is a geometry-qualifier on top of delivery. Our footprint vocabulary doesn't capture attack-position requirements.
7. **Counter skill** — each class has a specific "counter" ability for breaking boss attack patterns. Engine has no counter mechanic analog.
