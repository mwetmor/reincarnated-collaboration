Infinite stash tool for Grim Dawn.

GD Stash is written in Java and stores all items in a database, so it truly is unlimited. It also reads the information from database.arz into its own tables, so it does not always have to decode them after the initial setup.

[details="Downloads"]
**[Download Version 1.8.2g from ModDB](http://www.moddb.com/mods/gd-stash/downloads/gd-stash)**


**[Download Version 1.8.2g from Nexusmods](https://www.nexusmods.com/grimdawn/mods/2/)**
[/details]

[details="Features"]
[ul]
[li] Import necessary information from Grim Dawn's files[/li]
[li] Mass import items from the shared stash and characters to the internal DB (upload a directory with many stash and characters files at once)[/li]
[li] Transfer items between the shared stash and GD Stash[/li]
[li] Transfer items between the characters and GD Stash[/li]
[li] Export and import all stored items in a custom format for backup purposes[/li]
[li] Overview of collected / missing items[/li]
[li] Custom crafting of items (select item, prefix, suffix, etc.)[/li]
[li] Editing of some character information[/li]
[/ul]

[/details]
