### WARN-E3-1 · For the 19 emitter-wrapped symbols, the classifier keys on the wrapped object's NAME only, so WARN-1's discrimination is lost in emitter runs (#75 cl. 6) → before E4

`classify()` accepts an emitter wrapper as `kc2` if **any** `obj:` name in its (nested) closure description starts with `reincarnated.simulation.kc2.`. It accepts it as `rulebook` if any name contains `join2_rulebook`. Neither the shallow closure description (E3b) nor the nested one (E3c) carries the wrapped object's **fingerprint**, only `obj:<__module__>.<__qualname__>`.

**Demonstrated at this Gate.** The probe compiles the emitter's own `_ab` wrapper shape at the emitter's path and wraps three different inner objects:

| Inner object of the emitter wrapper | `classify()` | closure description |
|---|---|---|
| the sealed `intake.armour_branch` | `('emitter-wrapper', 'kc2')` | `['obj:reincarnated.simulation.kc2.intake.armour_branch']` |
| **re-homed** `armour_branch` (nc8f shape: same code, copied globals) | **`('emitter-wrapper', 'kc2')`** | **identical** |
| **`functools.wraps` delegate that halves the result** (nc8h shape) | **`('emitter-wrapper', 'kc2')`** | **identical** |

So in an **emitter** run (the ORACLE half, every JOIN run, and every E4 control or parity run made through the emitter), the per-cell record check **cannot see** a re-homed or wraps-style substitution of any of the 19 wrapped symbols. These include `intake.armour_branch`, `IntakeFold.physical`, `ThreatEngine.resolve_attack`, `threat.probability_to_hit`, `run.simulate_wave` and the summon `swing`. That is exactly what nc8f/nc8g/nc8h prove the census **can** see, but only in § 4.7 children, which run no emitter. **No emitter-mode negative control exists for the amended classifier.** This is the "an amended instrument without a fresh control" shape, for the third time in this lap.

**What it does not touch:**
- The golden master: the ROWSETs and FILEs are equal, and § 2 shows the forms on the path.
- The census in § 4.7 runs.
- The classifier still catches any object whose `__module__` names `join2_rulebook` sitting on a do-not-substitute symbol.

**Fix (before E4, ALONE, instrument):**
1. The witness fingerprints the **innermost wrapped callable** of an emitter wrapper with the **full** WARN-1 fingerprint, under `wrapped_fp`, not as a name. The emitter wrapper's own code is pinned by the emitter's FILE sha.
2. `classify()` compares that inner fingerprint against the **sealed census** for do-not-substitute rows, and against the **bind log's installed object** (its fingerprint, recorded at install) for substituted rows. "Any ref matches" is dropped.
3. **A control, predicted first:** one emitter cell (NON-GRADED-CONTROL) with `intake.armour_branch` re-homed onto a copied globals dict before the emitter wraps it. Predicted: that cell's record RED on exactly `intake.armour_branch`, every other cell GREEN, J-S8 still 7/7 (a delegate that changes nothing).
